# vrscan

Неофициальный конвертер и веб-вьюер для сканов Unity-сцен формата
`VRGirlz` — превращает купленную папку с данными в glTF, который можно
смотреть на плоском экране или в VR (WebXR), с переключателем качества под
разные шлемы.

> **Дисклеймер:** это неофициальный инструмент. Он конвертирует только те
> файлы, которые пользователь уже купил; в репозитории нет ни одного
> ассета вендора. Полный текст — в [`DISCLAIMER.md`](DISCLAIMER.md).

## Статус

Фаза 0 (этот чекаут): каркас репо, промежуточное представление (IR) сцены,
бэкенд-читалка на UnityPy, сборщик сцены, схема `manifest.json` и команда
`vrscan scan`, которая читает папку с данными и печатает, что нашла (позы,
части, уровни LOD, текстуры), ничего не записывая. Экспорта в glTF пока
нет — это Фаза 1.

## Быстрый старт

```bash
uv sync
uv run vrscan doctor
uv run vrscan scan "/path/to/VRGirlz-21-Nat_Data"
```

`vrscan scan` только читает: открывает `level0` и `sharedassets1.assets`
внутри папки с данными, обходит сцену и печатает таблицу поз, частей,
уровней LOD и метаданных текстур, плюс пик памяти (RSS) и время работы.

Архитектура — в [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md), заметки
для разработки — в [`docs/DEV.md`](docs/DEV.md).
